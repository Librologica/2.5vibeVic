# Changelog

First standalone VIC-20 SDK / Primo SDK autonomo VIC-20.

- Qualified monochrome and multicolor backends; 24 KB RAM expansion, PAL/NTSC.
- Backend monocromatico e multicolor qualificati; espansione 24 KB, PAL/NTSC.
- Four gallery demos, automatic/interactive, with complete rebuildable sources.
- Quattro demo delle gallerie, automatiche/interattive, con sorgenti ricompilabili.
- Portable external-output builder, explicit scene/route contract, public tests.
- Builder portabile con output esterno, contratto scene/percorso esplicito, test pubblici.
- English/Italian pipeline, memory, scene, assembly and qualification guides.
- Guide equivalenti inglesi/italiane per pipeline, memoria, scene, assembly e verifica.
- Runtime PRGs byte-identical to the qualified pre-packaging versions.
- PRG runtime byte-identici alle versioni qualificate prima del packaging.
