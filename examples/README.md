# Public example / Esempio pubblico

`galleries.json`: five rooms with connecting galleries, central hall, recesses
and piers. 32×32 map, 587 connected free cells. Same scene in both graphics modes.
Initial position (5.5, 6.5) cells, yaw 0 (+Y). Outer loop followed by inner loop.

Cinque sale con gallerie di collegamento, sala centrale, rientranze e pilastri.
Mappa 32×32, 587 celle libere connesse, identica nelle due modalità grafiche.
Partenza (5,5; 6,5) celle, yaw 0 (+Y). Giro esterno seguito da giro interno.
